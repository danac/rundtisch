Phase 1 Account registration (email only — no password)
Register (email)
POST /auth/register { email }
Create user · email_verified = false · no password hash
Store activation token (opaque, short-lived)
Send activation email
201 Created — no session
“Check your email to activate”
Phase 2 Email activation
Open activation link from inbox
Open /activate?token=…
POST /auth/activate
Set email_verified = true · issue short-lived temp JWT for passkey setup
200 Activated + temp access JWT
“Register your hardware passkey”
Phase 3 Passkey registration ceremony (WebAuthn)
Click “Add passkey”
POST /auth/webauthn/register/options
Bearer temp JWT
Generate challenge · store (TTL ~60s, single-use)
200 PublicKeyCredentialCreationOptions
cross-platform · residentKey: required · UV required
navigator.credentials.create({ publicKey }) — browser mediates CTAP2 makeCredential
CTAP2 makeCredential
rpId · user · algorithms
Touch key / enter PIN on device
attestationObject + clientDataJSON
private key stays on device
POST /auth/webauthn/register/verify
{ id, rawId, response, transports }
Verify attestation · store credentialId, publicKey, signCount · userHandle = opaque user.id
Passkey stores resident credential (rpId + userHandle + private key) — enables usernameless login later
201 Passkey registered
Phase 4A Usernameless login (resident / discoverable credentials)
“Sign in with passkey”
no email entered
POST /auth/webauthn/login/options
{ } empty body
Generate challenge only — no user lookup yet
200 RequestOptions
challenge · rpId · no allowCredentials · UV required
navigator.credentials.get({ publicKey }) — discoverable mode: passkey scans resident creds for rpId
CTAP2 getAssertion (discoverable)
challenge · rpId · no allowList
Touch key · pick account if multiple resident creds
authenticatorData + signature + clientDataJSON
+ userHandle (opaque user.id)
POST /auth/webauthn/login/verify
Lookup user by userHandle or credentialId · verify signature · check signCount · issue refresh token
200 access JWT + Set-Cookie: refresh
Phase 4B Login with email (fallback — allow-list credentials)
Enter email + “Sign in”
POST /auth/webauthn/login/options { email }
Lookup user + credentials · generate challenge · build allowCredentials list
200 RequestOptions with allowCredentials
Same ceremony + verify as 4A from here (CTAP2 getAssertion with allowList)
If email not verified → 403 at options (email path) or verify (usernameless path)
Phase 5 Authenticated API usage (JWT only — passkey not involved)
API call · Authorization: Bearer <accessJWT>
200 Resource JSON
Phase 6 Expired access token → refresh
Access JWT has expired
API call · Bearer expired accessJWT
401 { "error": "token_expired" }
POST /auth/refresh (HttpOnly cookie)
Validate + rotate refresh token (revoke old, issue new)
200 new access JWT + new refresh cookie
Retry request · Bearer new accessJWT
200 Resource JSON
If refresh fails → clear session → redirect to passkey login
Phase 7 Logout
Logout
POST /auth/logout
Revoke refresh token
204 Clear refresh cookie
Drop access JWT · redirect to passkey login

WebAuthn endpoints

  • POST /auth/webauthn/register/options
  • POST /auth/webauthn/register/verify
  • POST /auth/webauthn/login/options
  • POST /auth/webauthn/login/verify

Usernameless login

  • Empty body on login/options
  • No allowCredentials in response
  • Passkey discovers resident cred by rpId
  • Server resolves user via userHandle

Stored on server

  • credentialId + publicKey
  • signCount (clone detection)
  • aaguid, transports
  • ephemeral challenges (60s TTL)

Stored on passkey (resident)

  • Private key (never exported)
  • rpId + userHandle mapping
  • User PIN / biometric gate
Passwordless flow · resident credentials · usernameless discoverable login · JWT session after WebAuthn
