Phase 1 Registration
Register (email, password)
POST /auth/register
Create user · hashed password · email_verified = false
Store activation token (opaque, short-lived, single-use)
Send activation email (link + token)
201 Created — no session tokens yet
“Check your email to activate your account”
Phase 2 Email activation
Open activation link from inbox
Open /activate?token=…
POST /auth/activate { token }
Validate token · set email_verified = true · invalidate token
200 Activated — optional auto-login tokens
If auto-login: API creates refresh token → returns access JWT + Set-Cookie refresh · else prompt to log in
Phase 3 Login
Submit credentials
POST /auth/login
Verify password hash · check email_verified
200 access JWT + Set-Cookie: refresh
If unverified → 403 Email not verified · offer resend activation
Phase 4 Authenticated API usage
API call · Authorization: Bearer <accessJWT>
200 Resource JSON
Phase 5 Expired access token → refresh
Access JWT has expired
API call · Bearer access JWT (expired)
401 Unauthorized · { "error": "token_expired" }
POST /auth/refresh (HttpOnly cookie)
Validate refresh token · rotate (revoke old, issue new)
200 new access JWT + new refresh cookie
Retry original request · Bearer new access JWT
200 Resource JSON
Phase 6 Logout
Logout
POST /auth/logout
Revoke refresh token
204 Clear refresh cookie
Drop access token from memory · redirect to login
