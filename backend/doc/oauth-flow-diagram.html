Phase 1 Start OAuth (shared redirect — register or login)
“Sign up with Google”
or “Sign in with Google”
GET /auth/oauth/google/authorize
?intent=register|login · PKCE code_challenge
Generate state + code_verifier (PKCE) · store intent · TTL ~10m
302 Location: accounts.google.com/o/oauth2…
client_id · state · scope=openid email
Browser redirect to provider consent screen — same ceremony for register and login
Navigate to IdP · sign in · grant consent
Phase 2 Provider callback & token exchange
302 /auth/oauth/google/callback?code=…&state=…
GET /auth/oauth/google/callback
Load + validate oauth_state (single-use) · consume state
POST /token
code + client_secret + code_verifier
200 id_token + access_token
GET /userinfo (or decode id_token)
{ sub, email, email_verified, name }
Branch: new sub → Phase 3A · known sub → Phase 3B · email conflict → Phase 3C
Phase 3A OAuth registration (new user)
Lookup oauth_accounts by (provider, sub) → not found · email not taken
Create user · email_verified = true (IdP) · no password · create oauth_account
Create refresh token · sign access JWT
302 /oauth/success
Set-Cookie: refresh · hand off access JWT
Enter app (authenticated)
Reject if IdP email_verified is false → 403
Phase 3B OAuth login (returning user)
Lookup oauth_accounts by (provider, sub) → user_id found · load user
Create refresh token · sign access JWT
302 /oauth/success + JWT + refresh cookie
Enter app (authenticated)
If intent=login but no linked account → 404 “No account for this provider”
Phase 3C Email already registered — account linking
New sub but email matches existing user (e.g. password account)
409 { "error": "email_exists" }
Log in with password first
POST /auth/oauth/google/link
Bearer accessJWT · { code, state }
Verify session · exchange code · create oauth_account for current user
200 Provider linked
Phase 4 Authenticated API usage (JWT only — provider not involved)
API call · Authorization: Bearer <accessJWT>
200 Resource JSON
Phase 5 Expired access token → refresh
Access JWT has expired
API call · Bearer expired accessJWT
401 { "error": "token_expired" }
POST /auth/refresh (HttpOnly cookie)
Validate + rotate refresh token (revoke old, issue new)
200 new access JWT + new refresh cookie
Retry request · Bearer new accessJWT
200 Resource JSON
If refresh fails → clear session → redirect to login
Phase 6 Logout (local session only)
Logout
POST /auth/logout
Revoke refresh token
204 Clear refresh cookie
Drop access JWT · redirect to login
Does not sign the user out of Google/GitHub — only revokes local JWT session

OAuth endpoints

  • GET /auth/oauth/{provider}/authorize
  • GET /auth/oauth/{provider}/callback
  • POST /auth/oauth/{provider}/link

PKCE + state

  • code_challenge on authorize
  • code_verifier stored server-side
  • state single-use CSRF token
  • intent: register | login | link

Stored on server

  • oauth_accounts (provider + sub)
  • ephemeral oauth_states
  • users (nullable password)
  • refresh token hashes

Registration vs login

  • Same OAuth redirect ceremony
  • New sub → create user
  • Known sub → issue JWT
  • Email conflict → link flow
Authorization Code + PKCE · OIDC userinfo · JWT session after OAuth · same refresh/logout as password auth
